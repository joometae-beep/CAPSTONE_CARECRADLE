# CARECRADLE

## Project Title

Web-Based CareCradle: A Maternal-Infant Health Monitoring System with SMS Alerts for Irosin Rural Health Unit

---

## User Roles

### Administrator

- Manage Midwife Accounts
- View Reports
- Dashboard
- System Settings

### Midwife

- Register Mother
- Manage Mother Records
- Prenatal Checkups
- Appointments
- Infant Records
- Medical Logs
- SMS Notifications

### Mother

- Login
- View Profile
- View Pregnancy
- View Infant
- View Appointments
- View Health Tips
- Receive Notifications
